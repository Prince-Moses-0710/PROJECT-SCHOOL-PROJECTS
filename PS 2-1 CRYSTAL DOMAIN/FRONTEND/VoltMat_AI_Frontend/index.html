How the system works

Designed around the workflow described in the research paper.

01

Material input

Working ion, concentration, composition, crystal system and space-group information are entered.

02

Feature vector

Chemical and elemental descriptors represent the electrode material.

03

PCA + ML

The feature space is reduced and the selected DNN, SVR or KRR model predicts voltage.

04

Result

The estimated average voltage and a voltage-profile visualization are returned.

Project note

This frontend is the presentation layer; the actual scientific prediction should come from your trained model.

The paper describes a dataset of electrode-voltage instances and a feature representation containing 237 features, followed by normalization and PCA reduction to 80 principal components before ML prediction. This UI mirrors those stages without pretending that the browser itself is performing the trained scientific calculation.
